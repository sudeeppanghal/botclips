# BotClips / Parjapati SMM UI/UX Asset Kit

This package is a **recreated implementation asset kit** based on the supplied UI concept. The original generated mockup is a flattened image, so individual source vectors/3D renders are not recoverable pixel-for-pixel; the included assets are clean, editable SVG recreations intended for implementation.

## Contents
- Brand/logo SVGs
- Navigation and status icons
- Social platform icon set
- Robot mascot illustration
- Growth globe illustration
- Growth bars illustration
- Hero and dark CTA backgrounds
- CSS design tokens
- Reusable component snippets
- Demo dashboard data
- Brand guidelines

## Recommended stack
React / Next.js + Tailwind CSS + Framer Motion + Recharts/Lucide.

## Important
Use these assets as editable source material. Replace demo metrics, testimonials and service claims with verified production data before launch.
